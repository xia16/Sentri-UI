# Piglet search and identity

Figma nodes: `2952:33862`, `2952:34352`, `2952:34434`, `2952:34476`, `2952:34860`, `2952:34972`.

## Intent

Offer fast identification methods without turning each method into a separate permanent workflow.

## Interaction

- Search filters the existing piglet roster by ear tag or ear notch.
- **Scan tag** opens the same identity editor with a scanned value prefilled.
- **Choose ear notch** opens the editor with the notch field ready.
- **Add piglet** opens the same editor empty.
- Duplicate tags and notches are validation errors. They do not create additional animals.

All entry points converge on one identity record. Search and scan are navigation aids; saving the editor is the only operation that changes the litter record.
