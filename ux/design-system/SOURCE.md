# Where this design system comes from

This folder is the Sentri design system, and it is the source. The Claude
Design System artifact (https://claude.ai/artifact/RdQ4xnX1rzBiat8Z7YSjUT) is
republished from it at each version; it is never edited on its own.

Imported 2026-09-28 from the artifact's version `1790598266-2f7c`, which was
built from `ux/system` at `a8c87fc` on 2026-09-24. `tokens.json` is the token
contract: CSS reads its values, it does not invent them.

The August export (`Sentri Design System/`, `Sentri Design System 2/`, the
zip) predates Astra and is kept only in `archive/design-system-2026-08/`.
Do not design from it.
