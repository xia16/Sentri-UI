What happens when a commit moves a row across the lens. Law: state changes in place instantly; position changes only when the hand is done. The demo loops; the spec below is the front-end contract.

The contract

tPhaseWhat happens
0 msCommitThe record is written. Nothing is pending, ever.
0–200 msSettle in placeThe row transforms where it stands: line 1 flips to the done grammar (Pregnant · today), checkbox zone becomes ✎, green wash fades over ~1s. Lens counts and the pen aggregate tick immediately — the system-level receipt.
while activeHoldAny pointer activity in this pen resets the idle timer. Done rows stay put — the list never reflows under a working thumb.
idle 2000 ms
or scroll-past		DepartHeight-collapse, 180 ms ease, opacity out. A bulk mark departs as one group (one timer, simultaneous collapse). The row lands atop the finished lens (recency order).

The collapse — no measuring, no layout thrash

Each row sits in a grid wrapper; collapsing animates grid-template-rows: 1fr → 0fr. This animates height-auto without reading scrollHeight, causes one clean reflow, and works in every current WebView (Chrome 107+ / Safari 16+).

.rowwrap { display:grid; grid-template-rows:1fr; transition:grid-template-rows .18s ease, opacity .18s ease; } .rowwrap > div { overflow:hidden; min-height:0; } .rowwrap.depart { grid-template-rows:0fr; opacity:0; } /* remove from DOM on transitionend */ .row.wash { animation:wash 1.1s ease-out; } @keyframes wash { from { background:var(--green-wash) } to { background:transparent } } @media (prefers-reduced-motion: reduce) { .rowwrap { transition:none } .row.wash { animation:none } }

Hold logic

onCommit(row): writeRecord() // commit is instant, never gated on motion row.swapToDoneGrammar(); row.wash() counts.tick() // lens + pen aggregate, immediately departQueue.add(row); idle.reset() onAnyPointerEventInPen: idle.reset() onIdle(2000ms) or onRowScrolledPast: departQueue.collapseAllTogether() // one group, one motion

Notes for the hybrid shell

Pure CSS transitions on grid-template-rows, opacity, background — no JS animation loops, no native APIs, compositor-friendly. Do not animate top/margin of siblings; the grid collapse moves them for free. The count tick can be a 120 ms translateY swap but plain replacement is acceptable. Never delay the write for the motion: if the app is killed mid-animation the record is already committed and the next render is simply correct.
