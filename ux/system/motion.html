Task execution — the motion

Every commit sends its row to one of three destinies, and the destiny picks the motion. The law under all of them: state changes in place instantly; position changes only when the hand is done.

The bulk rule: one motion, one reflow. The bar clears first and the dock returns (selection is over), all three settle in the same frame with one shared wash, counts tick by 3 at once — lens, task overview, everywhere. Then one simultaneous group collapse. Never staggered: a stagger is the list churning N times under a hand that may already be working the next pen. Reading the matrix: A is the majority of all commits — most of what a farmer records changes a row without moving it, which is why the base motion is just flip-and-wash. B is the classic settle-hold-depart. C is B's mechanics with a different receipt.

The contract

tPhaseRule
0 msCommitThe record is written. Motion never gates the write — killed mid-animation, the next render is simply correct.
0–200 msSettleBulk: the selection bar clears first (translateY out, 200 ms) — the selection is over. All affected rows flip to their new grammar in the same frame, one shared wash (~1.1 s fade). Lens counts, pen census and aggregates tick immediately, by N.
—Destiny A stops hereAdvance-in-place rows never depart. The wash is the entire motion.
while activeHold (B · C)Any pointer activity in the list resets the idle timer. Done rows hold position — no reflow under a working thumb.
idle 800 ms
terminal 1200 ms
or scroll-past		Depart (B · C)After a settle beat of idleness — 800 ms for a cross, 1200 ms for a terminal exit, whose state deserves the longer read — or immediately once she scrolls out of view. One simultaneous group collapse (grid-template-rows 1fr→0fr, 180 ms) — never staggered, even across pens; the grid does the sibling movement for free. B lands atop the finished lens in selection order; C simply leaves, its receipt being the census tick (and, for transfer, the destination pen's card updating).
afterEmpty statesA pen whose last working row departs remains as header + census — no special motion. A working lens reaching zero shows its complete state; the lens chip counts already told the story.

The collapse — no measuring, no layout thrash

.rowwrap { display:grid; grid-template-rows:1fr; transition:grid-template-rows .18s ease, opacity .18s ease; } .rowwrap > div { overflow:hidden; min-height:0; } .rowwrap.depart { grid-template-rows:0fr; opacity:0; } /* remove on transitionend */ .row.wash { animation:wash 1.1s ease-out; } @keyframes wash { from { background:var(--green-wash) } to { background:transparent } } .bar.gone { transform:translateY(110%); opacity:0; } /* bulk: bar clears first */ @media (prefers-reduced-motion: reduce) { .rowwrap, .bar { transition:none } .row.wash { animation:none } }

Hold + bulk logic

onCommit(rows, destiny): writeRecords(rows) // instant, never gated on motion if bulk: bar.clear() // selection is over, 200 ms rows.forEach(r => { r.swapGrammar(); r.wash() }) counts.tickBy(rows.length) // lens + census + aggregate, same frame if destiny == ADVANCE: return // the wash was the whole motion departQueue.add(rows); idle.reset() onAnyPointerEventInList: idle.reset() onIdle(800 /* 1200 terminal */) or onScrolledPast: departQueue.collapseAllTogether() // ONE group, ONE reflow, no stagger

Hybrid-shell notes. Everything above is compositor-friendly CSS on grid-template-rows · opacity · transform · background — no JS animation loops, no native APIs. Do not animate siblings' positions manually; the grid collapse moves them. The count tick may be a 120 ms translateY digit swap; plain replacement is acceptable.
