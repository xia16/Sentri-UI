The fixed 6-state work-status pill: overdue (red fill), due (amber fill), upcoming (blue tint), done (green tint), blocked (gray), none (dashed — missing info, never zero).

```jsx
<StatusBadge status="overdue" />
<StatusBadge status="due">Due today</StatusBadge>
<StatusBadge status="none">Not checked</StatusBadge>
```

Never restyle or repurpose these colors decoratively.
