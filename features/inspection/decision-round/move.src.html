巡检转舍 Move

先找目标栏，再核对转舍。通过栏位、已选名单、单猪档案或异单元扫码与查找进入。

通用转舍怎么点异单元猪移入当前单元

通用转舍怎么点

要把猪从原栏移到另一个栏，点 Move。已经选好猪就直接看目标栏。从栏位进入时，先选对象再选栏。如果这个栏只有一头可转舍的有身份猪，直接看选栏图。

从栏位进去，选猪或填头数

巡检 → 点栏名 → Move → 选择猪只

能用耳标或耳缺识别的猪逐头选。其余只填这个栏要转走的总头数。服务端从来源栏有存量的批次里扣减。选好后点 Choose pen。

直接在巡检名单里填头数

巡检 → D4 最后一行 → 点行尾数字 → 输入 5 → Done

确定后巡检为本次 Actions 选择 5 头。如果要清掉这组勾选，可以取消勾选或填 0。回到名单后还可一起选有耳号的猪。

已经在巡检名单上选好，直接选目标栏

巡检列表、已选名单或 Scan → Actions → Move

三处共用同一张选栏图。图中已选 C1 的 000254 和 D4 的 5 头无身份猪，共 6 头。Move 直接用这些数量。

转完去哪查

来源栏 D4 或目标栏 C4 → Pen log

来源栏记移出，目标栏记移入。原有病症提示按新规则在来源栏清理，两边的转舍记录可查。

只转档案里这一头

猪只档案 → Actions → Move → 选房间和栏

可以换房间，再从地图挑栏。完成后回这头猪的档案看新位置。

分娩也用同一套选栏

母猪 Actions → Move，或 Piglets → 勾选 → Actions → Move

移动母猪时完成后回母猪档案。已选仔猪移动完成后回仔猪名单，在 Sent and moved 看到目标栏和头数。

异单元猪移入当前单元

扫码或查找后点异单元猪整行，选择移入方式。

从单元巡检扫码：点外单元猪可看档案或移入

巡检 → 底部 Scan → 读到 000306、000267、000430 → 点 000430 整行

000306 在 C2、000267 在 C1，都是 Unit 7 的猪，可以一起做批量操作。000430 在 Unit 6 / A2，点它那一行或右边箭头，打开「猪只在其他单元」弹窗。这里选查看档案，按 Back 回扫码时原来两头仍选中。

发现外单元猪：先看两种移入方式

扫码结果 → 点 000430 整行 → 只移入／移入并选中 → 在图上选栏

只登记位置就选「只移入」，以后还要对它做批量操作就选「移入并选中」。选栏页直接显示当前单元的地图。点一个栏，确认描边圈住目标，再点「核对转舍」。

只移入：猪到了新栏，原名单不变

Move only → 点 C1 → Review move → Confirm move → Back

适合只是把位置登记正确。收到成功回执后，它出现在 Unit 7 / C1，但不替你勾上。

移入并选中：成功后才加进批量

Move and select → 点 C1 → Review move → Confirm move → Back

适合猪确实到了新栏，而且你接下来还要对它记录治疗、备注等。回来先看已选数量和耳号。

从查找进入：同样可看档案或移入

巡检 → Search → 输入 000430 → 点结果 → 看档案或移入

输入耳号找到结果不会勾选。选了移入并选中，确认成功后回到同一个搜索词；此时结果在新栏，退回巡检就能看到加入的勾选。从查找点右侧扫码，则走上面的全单元扫码，Back 恢复原搜索。

提交后的短提示和回执

选择目标栏 → 核对 → 确认转舍

接口报错以扫码 No pig with this tag 同款短提示显示，留在核对页，可修改目标栏。断网时直接回原入口，联网确认后更新位置和勾选。截图使用样例回执。

流程依据

  • mobile_webapp @ 6a81b23e0：普通巡检把读到的耳号填入搜索；旧出栏流程进一步区分异单元和异栏。本巡检借鉴单元入口选目标栏，以及转舍成功后才按选择意图勾选的顺序（useOutboundScanException、OutboundFieldDetailPopup、useOutboundPigLocate）。旧出栏的已出栏撤回是独立操作，不带进巡检。
  • Sentri-UI 旧巡检设计 @ baa057e5：异单元保留归属，可看档案，选择只移入或移入并选择。旧稿确认键禁用，等待可追查转舍的接口。
  • Sentri-UI 巡检基线 @ af640dd3：本轮沿用共享 Lookup、Sheet、Row、Facts、Log 和现有任务页面；分娩和巡检共同使用栏位备注与报障表单。
