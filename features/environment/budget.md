# Environment sensor screen: budget

Polish: the budget decides the problem parts only; Keep is unchanged.

## Inventory

Per sensor: name, current value + unit, last-reading time, period (Today / 7 days), chart with 8 or 7 points and 3 axis labels, Low, High, history rows (time, value), "sample / offline" note. Devices: section status (Connected / Offline), fan name, mode status (Auto following schedule / Manual N%), mode choice, speed (Manual), Save setting, helper (offline / preview), applied stamp ("just now").

## Questions

1. Is the room right? (the reading, then Low / High)
2. Is it new? (last reading time)
3. Is the trend OK? (chart, period)
4. What is the fan doing, can I change it? (status, mode, speed, Save)
5. Why is it disabled? (offline helper)

## Levels

- Act now: none on a calm screen. When Manual is drafted, the dark Save setting is the single loud control.
- Watch: the reading (hero, mono 34px), the fan status line.
- Coming up: none.
- Settled: Low / High, Last reading, chart, period toggle (grey, quiet but at the 11px floor and above).
- Audit: Reading history (collapsed, with an affordance), table, offline note.

Cuts: none of the facts; the 7-day and offline notes stay. Nothing is enlarged except what is under the floor (quiet text to 12px, hero stays 34px, so the hero-to-support ratio stays). The fan speed value is the one fact that grows (Manual only), because it is what the worker sets.
