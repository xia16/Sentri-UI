# Conditions: information budget

Skeleton pass and owner replan (2026-10-17). The live screens were walked and shot first (390px): the Inspection list,
More actions (now Actions), Record health and the Conditions picker.

## House patterns (the live sibling each new part copies)

| New part | Live sibling | Kept from it |
|---|---|---|
| Group row (no ear tags) | the pig row beside it (approved animal row) | checkbox and height; the ID slot holds a struck-tag icon and `14 pigs`; the tags move to the context line, +N; a number field right |
| How many? at selection | the approved animal row's figure/state right; Measure + Numpad (piglet weights) | figure + word on the row (`3 · of 14`); the number pad in a short drawer |
| Selected page | the Selected drawer it replaces | the same rows and groups (Row select); no Clear: a page header has no corner action (Headers law) and Clear never sits in a footer, so each row unticks |
| Record health page | Record treatment (features/medicines) | fields only; Back + `Save · n` footer |
| Picker first level | Medicines picker (features/medicines) | search pinned, Recent above the groups, navigate rows |
| Symptom types | PickerField cascade-multi level | a navigate row opens a level of checkboxes; the parent shows `1 selected` |

## Group row (pigs without ear tags)

1. Its conditions, with how many pigs have each (`Coughing · 3`). 2. How many pigs (`14 pigs`, the icon says why they are a
group). 3. How many you act on (the field). Only when the pen has pigs without ear tags. 
Not shown: a row per pig, day counts, care words.

## The group count

1. How many (the figure). 2. All, or of how many. Chosen once, on the row; the dock, the Selected page and Save repeat the
total, never the breakdown. Record health asks nothing about who.

## Picker, first level

1. Search. 2. On these pigs (with who). 3. Recent. 4. Symptoms: the groups. 5. Diseases (the body systems; reportable ones marked on their rows).
Second lines only tell a row apart: who has it, a group's `N selected`, Reportable, a disease's other system. No item counts.
