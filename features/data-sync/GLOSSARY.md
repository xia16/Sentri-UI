# Data sync 数据同步

这里定义本机记录如何归属业务工作，以及哪些记录之间有先后关系。

## Language

**任务**：
一项有明确业务目标的工作范围，可以包含多条本机操作。同一任务不代表其中所有操作必须串行。

**本机操作**：
一次已保存在当前手机、等待服务端确认或已获确认的业务提交。一次批量提交即使涉及多头猪，仍是一条操作。
_避免_：把一次发送尝试或一次重试称为一条新操作。

**操作链**：
一组因共享对象的顺序约束或明确的前置关系而相连的本机操作；后续操作要等其前置操作解决，一步也可能同时有多项前置。
_避免_：把整项任务直接称为一条操作链。

**同步轨迹**：
同一条本机操作在发送、核对回执和重试过程中的状态经过。它不是新的业务操作。
