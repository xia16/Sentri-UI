## Design and implementation findings that do not need a product vote

- **Destination interaction:** `move.picker` says tapping a pen fills the review Picker, while the handover summary can read as if tapping a pen commits the whole transfer. The actual slide and PRD primary imply a separate transfer commit. The canvas should make the two taps unmistakable. `move.transfer-sow` uses two unit/pen fields; propose one shared destination picker and show both entry routes. This is a design call, with no change to placement semantics.
- **Feedback:** the old move deck says no toast. The later owner [feedback law](../../ux/design-system/README.md#feedback-after-saving-owner-2026-10-18) requires a count toast for several pigs and a toast when the result is not visible. The canvas should apply the current law.
- **Process death before saving:** no source promises persistent unsaved form fields. The safe design requirement is that reopening never claims a move happened; a new attempt can rebuild the draft from current server facts. Whether to restore partial field input is an implementation choice to test, not a transfer product rule.
- **Static baseline:** the four transfer slides in `ux/archive/workflows.html` and the sow sheet are design references. They cannot prove offline, server acceptance, conflicts or records in a second device. Scenario ledger rows stay Pending until a live walk is possible.
- **Screen reachability:** the current `move.transfer-sow` screen metadata replays `Actions` and then a sow-host selector, but the first step opens the unit-wide Actions sheet. The second selector is absent there, so a bare screen capture stops at Actions. The review canvas reaches the actual sow sheet through a live sow record and records the mismatch; the metadata needs correction only after canvas agreement.
- **Chinese coverage:** a 390-wide render of all five states found that `move.tagged`, `move.picker`, `move.mixed` and `move.after` ignore `?lang=zh`. The sow transfer sheet renders Chinese. The four deck pages need a Chinese pass during the post-agreement build; the English images in the review canvas do not count as bilingual approval.
