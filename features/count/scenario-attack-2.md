## 3. Questions only the owner can answer

1. **After a received pig leaves again, what must this task retain?** Recommend: retain the actual receipt and subsequent exit separately; replacing occupancy reconciles the task against those events, never invents a return to source. **N1, N5.**
2. **Who owns an arrival discrepancy when “were here” was already wrong and nobody can reconstruct it?** Recommend: a resident-baseline correction when known; otherwise an explicit unresolved delta, not a definite transfer shortage. Whole-pen counting remains unchanged. **N2.**
3. **Does an accepted non-task pig satisfy a selected task place, and must the receiver return her?** Recommend: save her actual placement without refusal or compulsory return; show her as extra, keep the intended ID outstanding, and record any physical return through Transfer. **N3, N12.**
4. **May the uncounted-pen pool span batches?** Recommend: use only anonymous pigs of the same batch, preserving the existing named-pig floor; define deterministic allocation, show inferred adjustments, and put the uncovered remainder on the sheet. **N7–N10.**
5. **When repairing a wrong batch placement, where do the unticked sows stand until rescanned?** Recommend: treat this as correction of the mistaken placement, not proof of a physical reverse move; keep their location unresolved until the correct pen is counted, with no second arrival. No undo or buffer split. **N11.**
