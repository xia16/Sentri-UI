# Sentri Mobile — UI kit

Interactive recreation of the Sentri mobile app (no source product existed; this is the reference implementation authored from the product brief).

Flow in `index.html`: **Today** (workload overview, by-task / by-location toggle) → tap a task or unit → **Unit screen** (due/upcoming/done tabs, bulk-select animals, record results via bottom sheet, live progress + toast). **Animals** tab shows ID search. All data is fake.

Screens compose the design-system components only — no UI is re-implemented here.
