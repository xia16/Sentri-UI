Renders a Lucide icon by kebab-case name; requires the Lucide UMD script (`https://unpkg.com/lucide@0.462.0/dist/umd/lucide.min.js`) on the page.

```jsx
<Icon name="clipboard-list" />
<Icon name="alert-triangle" size={24} color="var(--status-overdue)" />
```

Core vocabulary: clipboard-list (tasks), map-pin (location), calendar-clock (upcoming), alert-triangle (attention), clock (due), check/check-check (done/synced), tag (ear tag), scan-line, syringe, wheat (feed), arrow-right-left (movement), shield (biosecurity), cloud-off (offline).
